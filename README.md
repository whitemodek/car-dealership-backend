# Car Dealership Backend

Go-бэкенд для сайта автосалона с единым каталогом новых автомобилей и
автомобилей с пробегом. Проект находится в начале разработки.

## Сейчас реализовано

HTTP-сервер с проверкой конфигурации, таймаутами, структурированными логами,
корректным завершением и проверками состояния. Бизнес-API и PostgreSQL пока
не подключены. План и критерии готовности описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Запуск

Требуется Go 1.25.1 или новее. Из корня репозитория:

```sh
go run ./backend/cmd/api
```

Переменные окружения:

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| HTTP_ADDR | :8080 | Адрес HTTP-сервера |
| SHUTDOWN_TIMEOUT | 10s | Время завершения активных запросов, максимум 1m |

`GET /health/live` возвращает 200, когда процесс принимает HTTP-запросы.
`GET /health/ready` пока возвращает 503: зависимость PostgreSQL ещё не подключена.
Заготовка `/cars` удалена; каталог будет доступен под версионированным `/api/v1`.

## Проверки

```sh
go test ./...
go vet ./...
```

На Linux также выполняется `go test -race ./...`. CI запускает эти проверки
и проверку форматирования. Установка в настоящий автосалон потребует
завершения бизнес-сценариев и проверок из архитектурного документа.
